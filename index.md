## Execution Order

For each grant application run, use articles in this order:

```
1. Grant Types          → identify funder type and register
2. RFP Anatomy          → extract all requirements
3. Org Profile          → confirm all inputs are present
7. Alignment            → produce match report          ← Sub-build 1 output
8. Vocab Switching      → set language register
4. Narrative Sections   → draft all required sections   ← Sub-build 2 output
5. Evidence             → back every claim
6. Budget               → justify every line item
10. Output Formats      → assemble and check            ← Sub-build 3 output
9. Quality Rules        → enforce throughout all steps
```
