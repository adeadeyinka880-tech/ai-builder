⚡ What I'm Building

#1 · Highest Impact 🛡 PrairieFly DroneSec
Not Started
PrairieFly wins its first government drone security contract — tenders found automatically, RFP drafted in 30 minutes, not 3 days.
What's Happening Today

Manually checking 10+ procurement portals for drone/security tenders (121 browser visits in 14 days), then facing a blank page for proposal writing. Research is happening — but it's not converting to submitted bids.

Automated Version

Nightly agent monitors all portals for UAS/counter-drone keywords → morning digest with closing dates and fit scores. On match: paste tender PDF → Claude drafts full RFP response from PrairieFly's capability profile. Human reviews, submits.

Medium Lift · half day 6–8 hrs/week reclaimed Claude API + Python scraper + Gmail + Google Docs
#2 ⚖️ Law Firm
Not Started
Law firm associates spend their time on legal judgment — not manual case research and boilerplate drafting.
What's Happening Today

Associates spend 2–4 hours per matter manually searching CanLII for relevant precedents, then drafting client letters and memos from scratch. Billable time is eaten by lookup and formatting work anyone could automate.

Automated Version

Claude + CanLII MCP searches case law by jurisdiction and issue → extracts relevant precedents with citations → drafts client correspondence and memo sections. Attorney reviews, edits, signs. Research time cut from hours to minutes.

Medium Lift · half day 8–12 hrs/week per firm Claude API + CanLII MCP + Google Docs
#3 🏥 Healthcare
Not Started
Healthcare admin staff process patient intake, referrals, and prior authorizations without manually re-entering data across systems.
What's Happening Today

Staff spend 20–40 minutes per patient manually keying the same data into the EHR, insurer portal, and referral forms — then drafting prior auth letters by hand and waiting days for decisions.

Automated Version

Claude reads intake forms, pre-populates EHR fields and prior auth templates, flags missing info before submission, and drafts referral letters. Human confirms and sends. HIPAA-compliant with data staying in client systems.

Big Build · multi-session 10–15 hrs/week per clinic Claude API + FHIR/EHR integration + Anthropic Enterprise (HIPAA BAA)
#4 🧾 Accounting
Not Started
Accounting firms close client books and deliver management reports 3× faster — AI handles categorization and reconciliation, staff handle judgment calls.
What's Happening Today

Staff manually categorize transactions, reconcile accounts, and format monthly reports in Excel — hours per client per month. Repetitive work that scales poorly as client count grows.

Automated Version

Claude + Xero/QuickBooks API pulls transactions, categorizes by client rules, flags anomalies for staff review, and generates formatted management reports. Staff review exceptions and approve. Month-end drops from days to hours.

Medium Lift · half day 6–10 hrs/week per firm Claude API + Xero MCP or QuickBooks API + Google Sheets
#5 🛡 Insurance
Not Started
Insurance brokers process claims intake and policy comparisons in minutes — no manual policy lookup, no re-keying claim details.
What's Happening Today

Brokers manually collect claim details from clients, cross-reference policy schedules, and draft adjustment letters — bottlenecked by lookup and formatting work that adds days to every claim cycle.

Automated Version

Claude reads claim submission documents, matches against policy terms, generates coverage analysis and adjustment recommendation, and drafts client communication. Broker reviews and approves. Turnaround drops from days to same-day.

Medium Lift · half day 5–8 hrs/week per broker Claude API + Socotra MCP + document ingestion
#6 🏛 Municipalities
Not Started
Municipal staff process permit applications and prepare council briefings without manually cross-checking bylaws or formatting reports.
What's Happening Today

Staff manually review permit applications against bylaw requirements, prepare staff reports for council, and track procurement thresholds — all in separate systems with no workflow automation. Review cycles take weeks.

Automated Version

Claude reads application submissions, checks against bylaw rules and zoning schedules, identifies deficiencies, and drafts staff reports and approval or rejection letters. Council gets pre-formatted briefing packages. Review time cut by 60%.

🏗 Sprint 2 — What I Built

#1 · Dashboard 📋 Kanban + Notion
Shipped
A live Kanban board wired directly to Notion — drag a card, the database updates in real time. No manual status tracking, no copy-paste between tools.
What I Built

ai-builder-dashboard.html: 7 automation ideas as draggable cards across Suggested / To Build / In Progress / Done columns. Animated gradient mesh background, confetti on Done, priority badges, effort and hours pills.

The Backend

AI Automation Roadmap database in Notion. /api/roadmap serverless handler: GET loads all rows on page open, PATCH fires on every card drop. State lives in Notion — board reloads anywhere, any device, always current.

Medium Lift · 1 session Zero manual status updates Vanilla JS + Notion API + Vercel serverless
#2 · Agent 🤖 Automation Advisor
Shipped
A Claude Code skill that reads my live roadmap and session history, then delivers a 60-second briefing: top priorities, anything stalled, and one automation to add next.
What It Does

Runs two parallel subagents on /automation-advisor: Mode 1 fetches the Notion roadmap and surfaces High-priority items and anything needing definition. Mode 2 scans recent Claude Code session transcripts for manually-done tasks worth automating.

The Output

A structured briefing: ranked priorities, a flag for the least-defined In Progress item, and 1–2 card-title suggestions for the Suggested column. Mode 3 (Build Planner) scopes any item into a full sub-build plan and writes it back to Notion.

Quick Build · 1 session 60-sec daily briefing Claude Code Skill + Notion MCP + filesystem scan
#3 · Deploy 🚀 Vercel
Shipped
All three portfolio pages are publicly deployed on Vercel — shareable links, live Notion API, auto-deploys on every git push.
What's Live

Three HTML pages served as static files. /api/roadmap and /api/submit running as Vercel serverless functions. NOTION_TOKEN and NOTION_DATABASE_ID injected as production env vars — no secrets in the repo.

The Stack

GitHub repo ai-builder → Vercel project linked via CLI. vercel --prod on every release. vercel.json rewrites root to the dashboard. Local dev runs the same handler code via Express — no divergence between local and prod.

Quick Build · 1 session Auto-deploy on push Vercel CLI + GitHub + Node.js serverless
