# Funder-Org Alignment Methodology

When to use: Sub-build 1 — score the org against funder criteria and produce the match report that drives all narrative drafting.

---

## The 5-Step Process

**Step 1 — Extract funder priorities** (from RFP)
- Stated mission and funding pillars
- Explicit evaluation criteria + point weights
- Implicit priorities: language used repeatedly, what the overview emphasizes

**Step 2 — Extract org capabilities** (from org profile)
- Active programs, populations served, geographic footprint
- Track record: past grants, outcomes
- Staff expertise, partnerships, financial stability indicators

**Step 3 — Score alignment** (per criterion)
| Score | Meaning |
|---|---|
| 5 | Direct experience, evidence, and outcomes in this exact area |
| 4 | Relevant experience with minor gaps |
| 3 | Partial match — requires reframing or additional context |
| 2 | Weak match — significant gap to address |
| 1 | Little to no relevant evidence |

For each score: one-line justification citing specific org profile evidence. Score ≤3 → note reframe strategy.

**Step 4 — Identify differentiators**
Top 2–3 areas where org scores highest AND funder weights most heavily → lead the narrative with these.

**Step 5 — Flag gaps**
Score ≤2 → flag as gap. For each: suggest reframe strategy (adjacent experience, partnership, capacity commitment).
Flag: `[HUMAN: review this gap — consider addressing directly or reframing]`

## Inferred Criteria Handling
- No explicit criteria → derive from program description
- Label entire table `[INFERRED — not stated in RFP]`
- Require human confirmation before using inferred criteria to drive the narrative

## Match Report Output Format
```
FUNDER SUMMARY: Name | Deadline | Award | Eligibility confirmed
REQUIRED SECTIONS: [name] — [limit]
ALIGNMENT SCORES: Criterion | Weight | Score | Evidence
TOP 3 DIFFERENTIATORS
GAPS TO ADDRESS: Criterion | Score | Reframe strategy
```

## What It Feeds
Match report → input to Sub-build 2 (narrative drafting). Every section leads with differentiators; gaps addressed using reframe strategies.
