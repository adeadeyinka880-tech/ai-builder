# Output Formats & Submission Standards

When to use: Sub-build 3 — assembling, formatting, and preparing the final document for submission.

---

## Document Structure Rule
Always assemble in **RFP-specified section order** — not drafting order.

After assembly, produce a section order checklist:
```
[ ] 1. Executive Summary — 247/250 words ✓
[ ] 2. Organizational Background — 498/500 words ✓
[ ] 3. Project Description — 892/1000 words ✓
[ ] 4. Evaluation Plan — 445/500 words ✓
[ ] 5. Budget — attached ✓
HUMAN: verify section order matches RFP before submitting
```

## Format by Submission Type

**Online Portal**
- Character limits ≠ word limits — check which unit the portal uses
- Some portals strip formatting — write for plain text; paste via plain text editor first
- Save progress frequently — portals time out

**Document Upload (PDF/Word)**
- Follow font, size, margin rules exactly
- File naming: funder's convention if specified; otherwise `[OrgName]_[ProgramName]_[Year].pdf`
- Convert to PDF unless Word is specifically required

**Email Submission**
- Subject line: exact format specified in RFP
- Send from the contact email listed in the application

## Common Required Attachments
| Attachment | Notes |
|---|---|
| Charity/nonprofit registration | Current and valid |
| Audited financial statements | Check whether prior or current year |
| Current year operating budget | Full org budget, not project budget |
| Board member list | Names, roles, sometimes affiliations |
| Letters of support | On partner letterhead, signed, dated within 6 months |
| Logic model / theory of change | Required by some funders |

## Word & Character Count Standards
- Word count: use word processor built-in tool — not estimated
- Character count: includes spaces unless RFP says "without spaces"
- Page limits: at specified font and margins — never reduce font to fit
- Appendices: check if they count toward the page limit

## Pre-Submission Checklist
```
[ ] All required sections present and in RFP order
[ ] All word/page limits met
[ ] All [HUMAN: verify] flags resolved
[ ] Budget narrative figures match spreadsheet exactly
[ ] All required attachments included with correct filenames
[ ] Eligibility confirmed
[ ] Deadline confirmed (date, time, time zone)
[ ] Submission method confirmed
[ ] Confirmation receipt requested or screenshot saved
```
